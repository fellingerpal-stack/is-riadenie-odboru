IS Riadenie odboru v0.16.1

1. V StackBlitz nahrajte install-v0161-ui-iam-fix.mjs vedľa package.json.
2. Spustite: node install-v0161-ui-iam-fix.mjs
3. Spustite: npm run build
4. Nahrajte obsah priečinka github-files do GitHub main so zachovaním ciest.
5. V správnom Supabase projekte spustite IS_Riadenie_odboru_v0.16.1_IAM_DATABASE_FIX.sql.
6. Po Vercel deploymente použite Ctrl+Shift+R a v IAM kliknite Obnoviť.
