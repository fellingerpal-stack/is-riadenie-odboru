IS Riadenie odboru 0.9.0 – nasadenie iba zmenených súborov

1. Rozbaľte ZIP.
2. V StackBlitz nahraďte/pridajte všetky súbory podľa zachovanej štruktúry.
3. Súbor supabase/schema_cmdb_v09.sql zatiaľ nemusíte spúšťať.
4. Spustite npm run dev.
5. Obnovte náhľad cez Ctrl + F5.

Kontrola:
- dole vľavo verzia v0.9.0,
- v menu položka CMDB / Aktíva,
- priama adresa #/cmdb,
- v RACI už nie je prázdny blok medzi legendou a filtrami.

Nové npm balíky sa nepridávali, preto npm install nie je potrebné.
