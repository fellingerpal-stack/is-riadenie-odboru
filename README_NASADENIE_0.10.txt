IS RIADENIE ODBORU 0.10.0

Najistejsie nasadenie v StackBlitz:
1. Nahrajte install-v010-complete.mjs do korena projektu vedla package.json.
2. Zastavte Vite cez Ctrl+C.
3. Spustite: node install-v010-complete.mjs
4. Spustite: npm install
5. Spustite: npm run dev
6. Obnovte nahlad cez Ctrl+F5.

Po nasadeni bude aplikacia v lokalnom demo rezime, pokial nie su nastavene VITE_SUPABASE_URL a VITE_SUPABASE_ANON_KEY.
Pre realne prihlasenie postupujte podla SUPABASE_SETUP_0.10.md.
