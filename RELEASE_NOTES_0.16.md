# Release 0.16.0 – Spoločná architektúra ORIS a OIT

- presné formálne názvy odborov 3.1 a 3.2,
- opravené manažérske čítanie RACI OIT: A = konečná zodpovednosť, R = praktické vykonávanie,
- samostatné rebríčky vykonávania R, formálneho A a single-point-of-failure,
- nový spoločný modul Architektúra služieb v oboch pracovných priestoroch,
- prepojenie CRZP/APS, RVVI/SK CRIS/VedaTechnika, ISS, KOMIS, SciDAP, webového ekosystému, EOSC a ďalších služieb s DC VaV, platformami, servermi, sieťou, monitoringom a zálohovaním,
- zobrazenie CMDB, ticketov, problémov a zmien pri každej službe,
- označenie zdrojovo potvrdených a otvorených technických údajov,
- export architektonického registra do CSV.

Release nemení databázovú schému ani Supabase Storage.
