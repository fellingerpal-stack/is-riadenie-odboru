IS RIADENIE ODBORU 0.11.0 – SUPABASE

ODPORÚČANÉ NASADENIE V STACKBLITZ:
1. Nahrajte install-v011-complete.mjs vedľa package.json.
2. Zastavte bežiaci Vite cez Ctrl+C.
3. Spustite: node install-v011-complete.mjs
4. Spustite: npm run dev
5. Obnovte náhľad cez Ctrl+F5.

SUPABASE:
1. Spustite supabase/setup_v011.sql.
2. Vytvorte prvého Auth používateľa.
3. Doplňte e-mail v supabase/bootstrap_first_admin_v011.sql a spustite ho.
4. Doplňte .env podľa SUPABASE_SETUP_0.11.md.
5. Reštartujte Vite.

VERZIA APLIKÁCIE: 0.11.0
