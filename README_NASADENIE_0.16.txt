IS Riadenie odboru – release 0.16.0

1. Nahrajte install-v0160-architecture-raci.mjs vedľa package.json.
2. Spustite: node install-v0160-architecture-raci.mjs
3. Spustite: npm run build
4. Nahrajte zmenené súbory do GitHubu a počkajte na Vercel Ready.
5. Obnovte aplikáciu Ctrl + Shift + R.
6. Skontrolujte verziu v0.16.0, RACI OIT a nový modul Architektúra a závislosti.
