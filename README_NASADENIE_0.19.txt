IS Riadenie odboru – release 0.19.0
Spoločný pohľad a porovnanie RACI odborov

STACKBLITZ
1. Nahraj install-v0190-raci-comparison.mjs vedľa package.json.
2. Spusti:
   node install-v0190-raci-comparison.mjs
   npm run build

GITHUB
Nahraj obsah priečinka github-files so zachovaním ciest a potvrď commit do main.

VERCEL
Po stave Ready obnov aplikáciu cez Ctrl + Shift + R.
V ľavom dolnom rohu musí byť v0.19.0.

KONTROLA
1. Otvor RACI OIT a skontroluj kartu Porovnanie 3.1 / 3.2.
2. Otvor RACI maticu ORIS a skontroluj karty Ľudia a výkon rolí a Porovnanie 3.1 / 3.2.
3. V porovnaní preklikni osobný pohľad medzi 3.1 a 3.2.

SUPABASE
Pre tento release sa nespúšťa žiadny nový SQL skript.
Porovnanie používa existujúce synchronizované dáta aplikácie.
