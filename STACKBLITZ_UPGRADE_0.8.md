# Upgrade na v0.8.0

1. Pred nasadením si uložte aktuálny StackBlitz projekt.
2. Rozbaľte balík `LEN_ZMENENE_SUBORY`.
3. Nahrajte všetky súbory podľa zachovanej adresárovej štruktúry a potvrďte prepísanie.
4. Spustite `npm run dev`.
5. Obnovte náhľad cez `Ctrl + F5`.

Po správnom nasadení:

- v ľavom menu je položka `IAM / Prístupy`,
- dole vľavo sa zobrazuje verzia `v0.8.0`,
- priama cesta je `#/iam`.

SQL skript `supabase/schema_iam_v08.sql` je zatiaľ voliteľný. Existujúce snapshot ukladanie funguje bez jeho spustenia.
