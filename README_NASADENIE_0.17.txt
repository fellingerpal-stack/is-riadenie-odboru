IS Riadenie odboru – release 0.17.0

1. Nahrajte install-v0170-technology-catalog.mjs vedľa package.json.
2. V termináli spustite:
   node install-v0170-technology-catalog.mjs
   npm run build
3. Ak StackBlitz nemá git, nahrajte do GitHubu obsah priečinka github-files so zachovaním ciest.
4. Po úspešnom Vercel deploymente vykonajte Ctrl + Shift + R.
5. Vľavo dole musí byť verzia v0.17.0.

Supabase SQL sa pri tomto release nespúšťa.
