IS RIADENIE ODBORU 0.11.0 - SUPABASE

1. Nahrajte install-v011-complete.mjs do korena StackBlitz projektu vedla package.json.
2. Zastavte Vite cez Ctrl+C.
3. Spustite: node install-v011-complete.mjs
4. Spustite: npm run dev
5. Supabase nastavte podla SUPABASE_SETUP_0.11.md, ktory installer vlozi do projektu.
6. Po doplneni .env reštartujte Vite.
